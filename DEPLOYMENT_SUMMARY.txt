═══════════════════════════════════════════════════════════════════════════════
  REST API ENDPOINTS (AdminUserService)
═══════════════════════════════════════════════════════════════════════════════

Base URL: http://localhost:8201/api

1️⃣  GET /purchase-history
    Retrieve all purchase history with pagination
    Parameters: page, size, sort
    Response: JSON array of purchase records

2️⃣  GET /purchase-history/{id}
    Get specific purchase by ID
    Parameters: id (path parameter)

3️⃣  GET /purchase-history/customer/{customerId}
    Get all purchases for a customer
    Parameters: customerId, page, size

4️⃣  POST /purchase-history/filter
    Filter purchases by multiple criteria
    Body: customerId, startDate, endDate, minAmount, maxAmount, status

5️⃣  DELETE /purchase-history/{id}
    Delete a purchase history record
    Parameters: id (path parameter)

  EVENT FLOW ARCHITECTURE
═══════════════════════════════════════════════════════════════════════════════

┌─ PRODUCER (AdminOrderService) ─────────────────────────────────────────────┐
│                                                                             │
│  1. User updates order status to "COMPLETED"                              │
│  2. OrderEventProducer.publishPurchaseEvent() triggered                   │
│  3. PurchaseEvent object created with all order details                   │
│  4. Event serialized to JSON format                                       │
│  5. Published to Kafka topic: "customer-purchases"                        │
│  6. Broker acknowledges delivery (acks=all)                               │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─ MESSAGE BROKER (Kafka) ──────────────────────────────────────────────────┐
│                                                                             │
│  Topic: customer-purchases                                                │
│  ├─ Partitions: 1                                                         │
│  ├─ Replication Factor: 1                                                 │
│  ├─ Offset Commits: Automatic (consumer group tracking)                   │
│  └─ Retention: 7 days (default)                                           │
│                                                                             │
│  Message Format:                                                          │
│  {                                                                        │
│    "customerId": 123,                                                    │
│    "orderId": 456,                                                       │
│    "invoiceNumber": "INV-2025-001",                                      │
│    "totalAmount": 1500.00,                                               │
│    "status": "COMPLETED",                                                │
│    "orderCreatedAt": "2025-01-28T10:30:00",                              │
│    "paymentMethod": "CREDIT_CARD",                                       │
│    "orderItems": [...]                                                   │
│  }                                                                        │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─ CONSUMER (AdminUserService) ──────────────────────────────────────────────┐
│                                                                             │
│  1. PurchaseEventConsumer listens to topic                               │
│  2. Consumer Group: "admin-user-service"                                 │
